# DECISION-LOG

Versi ringan ADR. Catat keputusan arsitektur/desain yang gak perlu ADR baru. Format: tanggal, keputusan, alternatif, alasan.

Format:

```
YYYY-MM-DD
Keputusan: ...
Alternatif: ...
Alasan: ...
Status: APPROVED / REJECTED / SUPERSEDED_BY
```

## Cara Pakai

1. Setiap keputusan desain yang signifikan (bukan typo/refactor) masuk sini.
2. Kalau keputusan butuh dokumen terpisah, bikin ADR — ini hanya untuk keputusan ringan.
3. Status SUPERSEDED_BY merujuk ke entri atau ADR yang menggantikan.
